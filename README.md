# ロックンロールマップ｜世界のロックバンド出身地マップ

**▶ サイトはこちら：https://mosh696job-lab.github.io/rocknroll-map/**

世界700組以上のロックバンド・アーティストの出身地を、世界地図で見られるサイトです。
年代・ジャンル・バンド名で絞り込みができます。

- [バンド一覧](https://mosh696job-lab.github.io/rocknroll-map/bands/)
- [日本出身のロックバンド一覧](https://mosh696job-lab.github.io/rocknroll-map/country/japan/)
- [イギリス出身のロックバンド一覧](https://mosh696job-lab.github.io/rocknroll-map/country/uk/)
- [アメリカ出身のロックバンド一覧](https://mosh696job-lab.github.io/rocknroll-map/country/usa/)

---

このリポジトリはサイトのソースコードです。
バンドのデータは `index.html` の中にあり、`tools/build-pages.mjs` でバンドごとのページと `sitemap.xml` を自動生成しています。
